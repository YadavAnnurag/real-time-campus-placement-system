# Real-Time Campus Placement & Application Tracking System

This project is a web-based system developed as a final year project to manage campus placement activities with real-time application status updates.

## Features
- Student application tracking
- Admin status updates
- Real-time updates using WebSocket
- React frontend and Node.js backend

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Real-Time: WebSocket (ws)

## How to Run Locally

### Backend
```bash
cd backend
npm install
node server.js

for Frontend
cd frontend
npm install
npm start
